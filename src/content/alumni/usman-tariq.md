## From Rawalpindi to a developer role abroad

I was the student who preferred writing code to making map layouts. In final year I built a small web map for a local NGO using Leaflet and a PostGIS backend. It was rough, but it was public, and a recruiter found it.

After graduating I worked eighteen months at a software house in Islamabad building dashboards for a telecom client, then applied for a master's in Canada with that portfolio. The job offer came before the degree finished.

## What a GIS developer actually does

Less GIS than you think, more software engineering. Version control, code review, testing, and reading documentation. The spatial part is maybe a third of the day.

## Advice for juniors

- Learn JavaScript and Python properly. Pick one framework and finish a project in it.
- Do not wait for permission to publish. Put the project online, write a short readme, share it on LinkedIn.
